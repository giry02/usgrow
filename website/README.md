# UsGrow 회사 웹사이트

회사소개서 기반 반응형 정적 웹사이트입니다. 빌드 및 외부 패키지 없이 실행됩니다.

## 미리보기

공개 웹사이트: https://giry02.github.io/usgrow/

저장소 루트에서 `python -m http.server 15873`을 실행한 후 http://localhost:15873 에 접속합니다.

## 문의 이메일 변경

저장소 루트 `config.js`의 `contactEmail`을 수정하세요. 표시 주소, 문의 mailto 링크, 솔루션별 문의와 주소 복사에 공통 적용됩니다. 현재 설정은 `help@usgrow.co.kr`입니다. 문의 메일의 기본 제목은 같은 파일의 `contactSubject`입니다. 이메일 발송은 방문자의 메일 앱에서 이루어집니다. 서버 메일 발송이나 문의 데이터 저장 기능은 없습니다.

게시판, 문의 폼, 회원가입, 방문자 추적 도구는 포함하지 않습니다.

## 파일 구성

- `index.html`: 페이지 내용과 구조
- `styles.css`: 브랜드 스타일과 반응형 레이아웃
- `app.js`: 제품 선택, 연도별 사업 이력, 모바일 메뉴, 이메일 복사
- `config.js`: 문의 주소 설정
- `assets/`: 기존 로고, 회사소개서, 로컬 서체와 SVG 일러스트
- `output/어스그로우_회사소개서.html`: 브라우저에서 보는 회사소개서

위 경로는 모두 저장소 루트를 기준으로 합니다.

## 원본 및 콘텐츠

`output/어스그로우_회사소개서.html`과 `output/어스그로우_회사소개서_최종.pptx`를 기반으로 구성했습니다. 2026년 사업 이력과 인원은 10월 회사소개서 기준이며 2025년 확정 매출을 사용합니다. 제품 그래픽은 기능 설명용 예시입니다. 공식 파트너, 인증, 성과 향상률 등 원본에 없는 주장을 추가하지 않았습니다.

수정 사항을 `main` 브랜치에 push하면 GitHub Pages에 자동 반영됩니다. Pages의 공개 소스는 `main /`이며 `.nojekyll` 파일을 유지하세요.
